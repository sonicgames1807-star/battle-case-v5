# Case Clash Lab

Адаптивный симулятор виртуальных кейсов. 37 оригинальных кейсов с ценой до 1 триллиона бесплатных жетонов, 259 разных предметов и серверные аккаунты. Реальных денег, пополнения и вывода нет; режимы используют только игровые жетоны.

## Локальный запуск

Нужен Node.js 20 или новее; сторонние npm-пакеты не используются. Секрет администратора не входит в репозиторий. Перед запуском создай `.env.local` из `.env.example` или задай переменную окружения `CCL_ADMIN_PASSWORD`.

```bash
npm start
```

Открой `http://localhost:8000`. Сервер хранит аккаунты в `.data/accounts.json`; для сохранения аккаунтов на хостинге подключи постоянный диск к папке `.data`.

## Развёртывание

Для аккаунтов и защищённой админ-панели нужен хостинг Node.js с HTTPS и постоянным хранилищем. GitHub Pages подходит только для статической демонстрации и не обеспечивает вход или серверные роли. На хостинге задай секрет `CCL_ADMIN_PASSWORD` (не короче 16 символов) и переменную `PORT`, если её требует платформа. Добавь постоянный диск для `.data`. Не загружай `.env.local` в Git и не публикуй пароль.

Админская роль задаётся сервером только аккаунту `admin`. Обычная регистрация всегда создаёт роль игрока. API выдачи наград доступен после серверной проверки админской сессии.

## Аккаунты и безопасность

- Регистрация без почты и личных данных; имя игрока и пароль.
- Пароли хешируются через Node `scrypt`; сессия хранится в HttpOnly, SameSite cookie.
- Админский секрет хранится вне репозитория. `.env.local` и `.data/` внесены в `.gitignore`; пример настройки доступен в `.env.example`.
- Сервер ограничивает попытки входа, размер запросов, диапазоны баланса и проверяет роль для админских операций.
- Сайт не подключает платежи и не обменивает предметы на реальные деньги или товары.

## Игровые функции

- 37 кейсов от 160 до 1 000 000 000 000 жетонов, включая отдельный мем-кейс.
- У каждого кейса своя семёрка добычи: 259 разных названий и 259 разных рисунков; предметы между кейсами не пересекаются.
- Отдельные вероятности редкостей для каждого кейса, просмотр содержимого, roulette-анимация и пропуск.
- Склад с сортировкой, поиском, фильтрами и заметной кнопкой продажи на каждой карточке; обмен добавляет половину виртуальной ценности в жетонах.
- Режимы «Ракетка», «Девятиэтажка» и «Магнитный кран», а также контракты и апгрейд.
- Синтезированные звуки открытия, выигрыша, проигрыша и действий режимов; звук можно выключить в шапке.
- Upgrade с круговым шансом, выбором цели, множителями ×1,25–×10 и тренировочным режимом.
- Серверные аккаунты, выдача жетонов и предметов администратором выбранному игроку.
- Case Battle против бота и дружеский раунд, ежедневные награды, задания, уровни, коллекции и история.

## Структура и графика

- `index.html` — оболочка приложения.
- `src/app.js` — экраны, режимы, игровое взаимодействие, аккаунты и админ-панель.
- `src/sounds.js` — локальные синтезированные игровые сигналы.
- `src/engine.js` — генерация выпадений и прогресс.
- `server.mjs` — сервер и API аккаунтов, сессий и администраторских наград.
- `data/cases.js`, `data/items.js`, `data/economy.js` — кейсы, добыча, вероятности и цены.
- `assets/cases/` — 37 локальных обложек WebP.
- `assets/items/` — 308 нарезанных WebP-рисунков; 252 назначены предметам.
- `assets/item-atlas-100.webp`, `assets/item-atlas-2.webp`, `assets/item-atlas-3.webp` — три контактных листа по 100 оригинальных предметов каждый.

Иллюстрации сгенерированы специально для проекта. Внешние изображения не загружаются. Изображения сжаты в WebP.
